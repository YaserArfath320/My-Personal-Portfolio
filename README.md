## 👨‍💻 Overview

Welcome to the official repository of **Yaser Arfath's Personal Portfolio**. 

Built as a lightweight, zero-dependency, ultra-fast single-page application with bespoke Vanilla HTML5, CSS3, and JavaScript, this portfolio showcases production-grade GovTech platforms, full-stack Agentic AI tools, engineering case studies, and interactive design systems.

### 🎯 Core Engineering Principles
- **Problem-First Architecture**: Understanding user journey and underlying data flows before writing code.
- **Production Usability**: Designing accessible, responsive interfaces that perform smoothly across devices.
- **Agentic AI Integration**: Leveraging LLMs, Cline SDK, and prompt-driven workflows to build next-generation applications.

## ✨ Key Portfolio Features & UI/UX

- **🪐 Ambient Cosmic Glow & Particle Engine**: Custom interactive HTML5 canvas with dynamic starfield, gentle mouse evasion, and golden constellation links.
- **🖱️ Interactive Cursor Spotlight**: Dual-layer desktop cursor tracking with dynamic amber illumination.
- **📱 Deep-Linked Case Study Router**: Full-screen modal case studies with URL hash routing (`#project-cdmp`, `#project-forge`), keyboard navigation (`ESC`), and breadcrumb navigation.
- **⚡ Zero Build Dependencies**: Instant 100/100 Lighthouse performance potential with native browser APIs.
- **📜 Vertical Scroll Progress Indicator**: Floating responsive progress pill reflecting active page depth.
- **📋 One-Click Email Copying**: Interactive clipboard handler with real-time feedback toast notifications.
- **🎨 Curated Design Tokens**: Dark luxury theme featuring golden amber accents (`#f59e0b`), Space Grotesk headings, and Anton display typography.

## 💻 Quick Start / Local Preview

Because this portfolio is built with pure Vanilla web standards, it requires **no package installations or compilation steps**.

### 1. Clone the repository
```bash
git clone https://github.com/YaserArfath320/My-Personal-Portfolio.git
cd My-Personal-Portfolio
```

### 2. Run locally
You can open `index.html` directly in any modern browser:

- **Option A (Direct File)**: Double-click `index.html`.
- **Option B (VS Code Live Server)**: Right-click `index.html` ➔ `Open with Live Server`.
- **Option C (Python HTTP Server)**:
  ```bash
  python -m http.server 3000
  # Open http://localhost:3000 in your browser
  ```
- **Option D (Node / npx serve)**:
  ```bash
  npx serve .
  ```

## 🚢 Deployment

This repository is ready for instant deployment on static hosting platforms:

### GitHub Pages (Recommended)
1. Go to repository **Settings** ➔ **Pages**.
2. Under **Build and deployment** ➔ **Source**, select `Deploy from a branch`.
3. Choose `main` branch and `/ (root)` folder.
4. Click **Save** — your site will go live at `https://<username>.github.io/<repo-name>/`.

### Vercel / Netlify
- Simply import the GitHub repository into your Vercel/Netlify dashboard and deploy with zero configuration (Root Directory: `./`).
